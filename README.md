# Programas de Estudio: PDF pendientes

Lista pública de los PDF de los **Programas de Estudio** (Currículum Nacional, Mineduc) que faltan por
descargar para el proyecto *curriculum-nacional-cl*. La página está en `index.html` y se publica con
GitHub Pages.

- Cada fila enlaza al PDF oficial en [curriculumnacional.cl](https://www.curriculumnacional.cl) y a la
  página del programa.
- Las casillas marcadas se guardan solo en el navegador de quien las marca.
- La lista se regenera desde el proyecto con `make publish-checklist PAGES=../programas-pendientes`
  (o `python manual_pdfs.py list` y copiando `data/manual/pendientes.html` como `index.html`).

Este repositorio no contiene los PDF ni código del proyecto, solo la lista de enlaces.
